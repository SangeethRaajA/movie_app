# Cineverse

Cineverse is a portfolio-style learning project built to explore how AI-assisted development can be used to design and ship a polished movie discovery experience. The project combines modern frontend architecture with TMDB-powered content to showcase practical UI, routing, and API integration skills.

## Why this project exists

This app was created as a hands-on learning project to experiment with:

- AI-assisted product building and component generation
- Next.js App Router architecture
- API-driven content experiences
- Responsive UI design and polished product presentation
- End-to-end feature implementation from planning to deployment readiness

## Featured Experience

- Elegant homepage inspired by modern streaming platforms
- Movie and TV browsing powered by TMDB
- Search experience with genre and country filters
- Dedicated pages for genres, country-based discovery, and top-rated titles
- Dynamic detail pages for richer content exploration
- Custom 404 experience for a complete product feel

## AI Agent Workflow

This project was developed with an AI-assisted workflow focused on learning and rapid iteration:

1. Define the product direction and page structure
2. Generate UI components and page layouts
3. Connect interfaces to TMDB API data
4. Refine the experience with responsive styling and navigation

This workflow highlights how AI agents can support product thinking, implementation, and refinement in a real project.

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a local environment file:
   ```bash
   .env.local
   ```
4. Add your TMDB API key:
   ```env
   TMDB_API_KEY=your_api_key_here
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```

## Available Scripts

- `npm run dev` – start the local development server
- `npm run build` – build the app for production
- `npm run start` – run the production build locally
- `npm run lint` – check for lint issues

## Project Structure

- `src/app` – route-based pages and layouts
- `src/components` – reusable UI building blocks
- `src/lib` – TMDB integration and shared helper logic
