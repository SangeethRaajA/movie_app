# Release Notes

## Version 1.0.0

### Highlights

- Built a polished movie and TV discovery experience using Next.js and TypeScript
- Added TMDB-powered browsing for featured releases, trending titles, and top-rated picks
- Introduced a portfolio-style homepage inspired by major streaming platforms
- Added search, genre, country, and top IMDb browsing flows
- Implemented dedicated movie and series detail pages
- Added a custom 404 page to complete the user experience

### Learning Focus

- Demonstrates how an AI-assisted workflow can be used to plan, build, and refine a modern web app
- Showcases practical experience with routing, API integration, responsive UI, and reusable components

### Technical Updates

- Migrated from a Vite-based setup to Next.js with App Router
- Integrated TMDB API for dynamic content loading
- Applied a Tailwind-based visual system for a cleaner, more modern interface
